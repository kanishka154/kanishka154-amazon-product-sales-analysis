# Amazon Product Sales & Customer Engagement Analysis

## Overview

End-to-end data analytics project analyzing Amazon product performance, pricing, reviews, purchases, and customer engagement using **Excel, SQL, Python, and Power BI**.

## Tools

* **Excel** — Data cleaning and analysis
* **SQL** — Data querying and business analysis
* **Python** — Data cleaning and exploratory analysis
* **Power BI** — Interactive dashboards and visualization

## Key Analysis

* Product performance and ratings
* Customer reviews and estimated monthly purchases
* Pricing and discount analysis
* Best-seller and sponsored products
* Customer engagement insights

## Power BI Dashboards

1. Executive Overview
2. Product Performance
3. Pricing & Discount Analysis
4. Customer Engagement & Sales Insights

## Skills

**Data Cleaning · Excel · SQL · Python · Pandas · Power BI · Data Visualization · Business Analysis**
